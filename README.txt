МОИ ФИЛЬТРЫ — Android project

Основа: текущая MoiFiltry v11.
Добавлено: нативное резервное копирование/восстановление JSON через системный выбор файла.

Сборка:
1. Открыть папку проекта в Android Studio.
2. Дождаться синхронизации Gradle.
3. Build > Build APK(s).
4. Установить APK на телефон.

Данные клиентов хранятся локально. Резервная копия создаётся вручную.
